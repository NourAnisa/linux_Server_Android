1 Quickstart (Drop-in Replacement Midtrans)

OpenQRIS dirancang 100% kompatibel dengan API Midtrans (Core API & Snap). Anda cukup mengganti Base URL dan memasukkan Server Key akun OpenQRIS Anda.

// Ubah konfigurasi Midtrans SDK ke OpenQRIS

const midtransClient = require('midtrans-client');


const snap = new midtransClient.Snap({

  isProduction: true,

  serverKey: 'OQ-server-prod-YOUR_SERVER_KEY',

  clientKey: 'OQ-client-prod-YOUR_CLIENT_KEY'

});


// Arahkan endpoint ke OpenQRIS Gateway

snap.apiConfig.set({

  serverKey: 'OQ-server-prod-YOUR_SERVER_KEY',

  isProduction: true

});

snap.apiConfig.baseUrl = 'https://openqris.jokicoding.web.id/api';

2 Autentikasi API

Setiap request HTTP ke OpenQRIS API diautentikasi menggunakan standar HTTP Basic Auth, di mana username adalah Server Key dan password dikosongkan.

# Header Autentikasi HTTP

Authorization: Basic base64(SERVER_KEY + ':')

Content-Type: application/json

Accept: application/json

3 Membuat Transaksi (Charge)

Endpoint POST /v2/charge menghasilkan Snap Token dan URL QRIS dinamis berisikan nominal pembayaran pelanggan.
